# About Gunman Search

Welcome to **Gunman Search**.

Guman Search is a privacy-focused metasearch engine built on top of SearXNG.

Instead of relying on a single search provider, Guman Search can query multiple search services and combine their results into one interface.

## Why Gunman Search?

Gunman Search is designed around a few simple principles:

- Privacy
- Open web access
- Multiple search sources
- Minimal tracking
- A clean and useful interface
- User control

## How does it work?

When you submit a search, Gunman Search sends the request to the configured search engines and collects their results.

The results are then presented through a single interface.

Gunman Search itself does not need to create a personal search profile to provide search results.

## Search categories

Gunman Search currently provides categories including:

- General
- Images
- Videos
- News
- Maps
- IT
- Science

## Technology

Gunman Search is powered by:

- SearXNG
- Docker
- Linux / WSL
- Multiple search providers

## Open source

Gunman Search is built using open-source software and is intended to remain transparent and customizable.
